A modern team task and workflow management platform built using the MERN stack. ToggleNest helps teams plan, organize, assign, and track tasks efficiently through an intuitive Kanban-style interface with real-time collaboration and project monitoring.

---

## ✨ Features

### 👥 User Management

* Secure User Authentication
* Role-Based Access Control
* Team Member Management
* JWT-Based Authorization

### 📋 Project Management

* Create and Manage Multiple Projects
* Project Descriptions and Deadlines
* Team Collaboration Workspace
* Project Progress Tracking

### ✅ Task Management

* Kanban Board Interface
* Drag-and-Drop Task Movement
* Task Assignment
* Priority Management

* Progress Dashboard
* Completion Rate Tracking
* Pending Task Monitoring
* Activity Logs

### 🔔 Productivity Features

* Real-Time Workflow Tracking
* Team Collaboration Tools

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/shravanip419/ToggleNest.git
cd ToggleNest
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
